# Atherless

A 2D platforming game built in Unity (C#), featuring physics-based movement, collision detection, and raycasting logic.

## About

Atherless is an early, semi-complete build of a 2D platformer developed as a personal project to practice game development fundamentals — including structured coding practices, debugging workflows, and the broader software development lifecycle.

This repository currently contains the compiled Windows build of the game.

## Status

🚧 **Work in progress** — this is an early playable version. No major known bugs, but features and polish are still being added.

## How to Run

1. Download or clone this repository.
2. Run `Atherless.exe` on a Windows machine.
3. No additional installation required — all necessary runtime files (Unity Player, DirectML, etc.) are included in the build.

## Features

- 2D platforming movement with physics-based controls
- Collision detection
- Raycasting-based interaction logic

## Built With

- [Unity](https://unity.com/) — game engine
- C# — gameplay scripting
